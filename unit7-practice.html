Part C · Comparing Quadratic Functions

Function A is graphed below. Function B is given by g(x) = x² − 6x + 5.

C Graph vs. Equation

1 Function A is graphed above. Function B is g(x) = x² − 6x + 5. Which function has the greater maximum value?
✓ Function B opens upward (no maximum), so only Function A has one — 5.
2 What is the y-intercept of Function B: g(x) = x² − 6x + 5?
Plug in x=0: g(0) = 0² − 6(0) + 5 → (0, 5)
3 Find the zeros of Function B: g(x) = x² − 6x + 5.
Factor: x² − 6x + 5 = (x−1)(x−5) = 0 → x = 1, 5

Part D · Transformations

The graph shows the parent function y = x² and a transformed version.

D Shifting the Parabola

1 How was y = x² transformed to create the graph shown?
✓ The vertex moved from (0,0) to (3,2).
2 Write the equation of y = x² after a shift left 4 and down 1.
Left 4 → replace x with (x+4). Down 1 → subtract 1 → y = (x + 4)² − 1
3 Write the equation of y = x² after a reflection over the x-axis and a shift up 3.
A reflection over the x-axis flips the sign: y = −x². Shift up 3 → y = −x² + 3
